## 🌸 About SISILY

**SISILY** is a premium beauty and skincare e-commerce website built around the idea of natural beauty, self-care and confidence.

The platform aims to provide customers with an elegant digital shopping experience where they can explore skincare and makeup products through a clean, intuitive and visually appealing interface.

With a soft lavender aesthetic, elegant typography and modern UI components, SISILY brings a luxury-inspired shopping experience to the web.

## ✨ Key Features

- **Premium Landing Page** — Modern hero section with elegant product presentation.
- **Product Discovery** — Dedicated shopping experience for beauty and skincare products.
- **Skincare Collection** — Explore skincare products and beauty essentials.
- **Makeup Collection** — Discover makeup and cosmetic products.
- **Offers Section** — Dedicated space for promotions and special deals.
- **Wishlist** — Heart-based wishlist interface.
- **Shopping Cart** — Convenient shopping bag interface.
- **Search Interface** — Product discovery through search.
- **Authentication UI** — Login entry point for customers.
- **Responsive Design** — Designed for a consistent experience across screen sizes.

## 🚀 Getting Started

Follow these steps to run SISILY locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/sisily.git
```

### 2. Navigate to the project

```bash
cd sisily
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the website.
